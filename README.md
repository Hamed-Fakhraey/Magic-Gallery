# 🌌 Magic Gallery

> An interactive, responsive, and dark-themed web gallery built with Vanilla JavaScript, HTML5, and CSS3 featuring modern Glassmorphism aesthetics.

[![GitHub Pages](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-brightgreen?style=for-the-badge&logo=github)](https://hamed-fakhraey.github.io/Magic-Gallery/)
[![Tech Stack](https://img.shields.io/badge/Stack-HTML5%20%7C%20CSS3%20%7C%20JS-blue?style=for-the-badge&logo=javascript)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

---

## ✨ Key Features

- 🔍 **Live Real-time Search:** Instant filtering of gallery cards by title as you type.
- ❤️ **Persistent Favorites System:** Add cards to favorites with data saved seamlessly in `localStorage`.
- 🎴 **Multiple Showcases:** Dedicated categories for Gaming, Live Wallpapers, and Supercars.
- 🎨 **Modern Glassmorphism UI:** Translucent cards, glowing hover effects, and sleek dark-mode aesthetics.
- 📱 **Fully Responsive:** Smooth navigation and layout adapted for mobile, tablet, and desktop screens.

---

## 🛠️ Built With

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** Vanilla CSS3 (Flexbox, Grid, CSS Variables, Glassmorphism Backdrop Filter)
- **Logic:** Vanilla JavaScript (ES6+, DOM Manipulation, LocalStorage API)
